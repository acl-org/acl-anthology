Historical checkpoints use the last main-branch commit before the first of each month (UTC), starting January 2026. Verification and ORCID status reflect each checkpoint, not today's status. Checkpoints before the July 2026 verified-author migration classify all pages as unverified; a legacy page has an ORCID if any of its associated author or editor names supplied one. Historical name resolution follows the library at that checkpoint, so the migration itself can also change the number of unique pages.
